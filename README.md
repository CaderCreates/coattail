# CoatTail

Smart-money signal tracker for iPhone. Live feed of Congressional trades, SEC insider filings, fund 13F holdings, and on-chain whale activity — all in one place.

[![App Store](https://img.shields.io/badge/App%20Store-Coming%20Soon-blue)](https://apps.apple.com)

## What it does

CoatTail aggregates publicly disclosed financial data from four sources:

- **U.S. Congress trades** via Quiver Quantitative
- **SEC Form 4 insider filings** via SEC EDGAR
- **SEC 13F fund holdings** via SEC EDGAR
- **Crypto whale wallet activity** via Blockchair

Tap any ticker to see who's been buying it across all four sources, with PnL vs SPY benchmark and a live price chart marking each insider trade.

## Features

- Cross-source consensus signals (when politicians + insiders + funds all agree)
- Insider cluster detection (≥3 insiders at same company in 14d)
- Per-row PnL vs SPY
- Hot signal badges
- Live Activity for incoming whale events
- Lock screen + home screen widgets
- Watchlist + simulated copy portfolio
- Daily summary, news per ticker, sector breakdown
- Multiple broker deep links (Robinhood, Webull, Public, TradingView)
